# legacy/ — Qt 旧栈归档（不参与运行，仅供审计参考）

> 本目录是 Aegis **早期 Qt 栈**（PyQt5）的完整归档，自 S2 起被
> WebView2 新栈（`../app/` + `../main_webview.py`）取代。
> **不参与任何运行路径**：CI 的 ruff/mypy/bandit 检查已排除本目录
> （口径一致：`--exclude legacy`），打包与发布均不引用。

## 归档内容

| 条目 | 说明 |
|---|---|
| `main.py` | Qt 旧栈入口（含旧式 JS 桥） |
| `app/` | 旧业务模块（含影子字段旧实现：do_not_track/safe_browsing 等） |
| `ui/` | Qt 界面组件 |
| `aegis.spec` | PyInstaller 打包脚本（旧栈） |
| `__pycache__/` | 编译缓存（忽略） |

## 保留原因

1. **影子字段审计**：旧栈承载了 `do_not_track`/`safe_browsing` 等声明的
   历史实现，供合规追溯（新栈已由独立模块重新实现）
2. **研读对照**：结构与安全设计决策可回溯旧实现
3. **不删除**：政府项目档案完整性，删除需走审批

## 操作约定

- **不要**把新代码放进本目录（新开发一律进 `../app/`）
- **不要**在新栈 import 本目录任何模块（已隔离）
- 静态检查：ruff `--exclude legacy` / bandit 豁免清单均不扫描本目录
  （存量风格问题属历史归档，不修）
- 迁移复核：仅审计需要时按需读取
