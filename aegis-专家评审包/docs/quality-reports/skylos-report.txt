# Skylos PR 扫描报告（P2-②，2026-08-15）

> Skylos 4.33.2（本地优先静态分析，Apache-2.0）
> 扫描范围：windows/aegis_source/app + main_webview.py（--severity high）

## 发现（高严重性 40 项）

### SKY-U001 未使用函数（35）
按模块归类：
- asset_scheme.py: wallpaper_url/ensure_registered（Qt 旧栈遗产，新栈 pywebview 不用）
- bookmark_store.py: remove_by_id/in_folder/add_folder/import_html（selftest/预留 API）
- database.py: vacuum/close（预留维护 API）
- fingerprint.py: 全部 6 函数（R7 可选模块接口，默认关闭未接入）
- history_store.py: add/all/search/suggest/delete_url/fulltext_search/clear/stats/most_visited（js_api 经 Api 类调用，直连检测误报）
- mcp.py: handle_request（MCP 服务器入口，经外部协议调用）
- paths.py: profile_dir/temp_dir/cache_dir/webengine_dir（预留目录 API）
- security.py: is_dangerous_download/normalize_credential_host（预留安全 API）
- threat_feed.py: parse_feed_line/fetch_feed/cache_path/refresh（后台线程调用，直连检测误报）

### SKY-U004 未使用类（3）
- asset_scheme.py: AegisAssetHandler（Qt 旧栈）；reader.py: ReaderDecision/ReaderView（R8 阅读模式，预留）

### SKY-U003 未使用变量（2）
- backdrop.py:_fields_；paths.py:DEFAULT_DATA_DIR_NAME

## 分析
- 多数为预留 API/新模块接口（fingerprint/reader/mcp 等 R7/R8/R3 落地）——设计为可选接入，非缺陷
- 少数为 Qt 旧栈遗产（asset_scheme 属 legacy 引用面）
- js_api 经 Api 类桥接的存储方法为静态直连误报（运行时经 js_api 调用）

## 结论
- Skylos 服务于'死代码/安全/机密'PR 门禁目标；本轮为基线扫描（首次），发现均为已知/预留项
- 不立即删除（政府项目谨慎：预留 API 是未来接入点）；后续接入或清理时逐项核对
